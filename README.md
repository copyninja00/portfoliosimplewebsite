Personal Portfolio Website

A simple 2-page personal portfolio website built using HTML and CSS.
This project showcases a basic portfolio layout including personal introduction, projects, and contact information.

Project Overview

This portfolio project was created to practice HTML structure, semantic tags, and basic web design concepts.
It contains two main pages that represent a typical personal portfolio website.

Pages Included

The main landing page that includes:

Personal introduction

Short description about me

Navigation to other pages

Basic portfolio layout

2. Contact Page

This page contains:

Contact information

Simple layout for connecting with the developer

Navigation back to the home page
